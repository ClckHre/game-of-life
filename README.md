# Game of life
  An implementation of Conway's Game of Life in C using the ncurses library

## Description
  Press *space* to advance the simulation

  Press *left mouse button* to change a cell's state

  Press *q* to quit

## Requirements
  - GCC
  - GNU make
  - ncurses

## Building
  Run:
  ```bash
  make
  ```

## Running
  Run:
  ```bash
  ./life
  ```
